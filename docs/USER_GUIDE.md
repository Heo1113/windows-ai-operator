# 사용 설명서

## 1. 기본 흐름

1. **모델** 화면에서 Strata(또는 OpenAI 호환 서버)를 연결합니다. [연결 확인] → 모델 선택 → [이 연결을 사용].
2. **작업 실행** 화면에서 요청을 적습니다. 예: `메모장을 열고 "테스트 문장입니다."를 입력해 줘.`
   - 특정 창에서 시작하려면 '시작 대상 창'을 고릅니다(목록에는 허용 앱 창만 나옵니다).
   - 폴더 목록이 필요한 요청은 [폴더 추가…]로 이번 작업에서만 읽을 폴더를 고릅니다(이름·크기·날짜만 읽음).
3. [계획 및 실행] → **계획 확인 창**에서 단계와 '승인이 필요할 것으로 보이는 단계'를 확인하고 [실행].
4. 실행 중 위험한 단계는 **승인 창**이 맨 위에 뜹니다. 대상·변경 내용·영향 범위·복구 방법을 확인하고 [승인하고 실행] 또는 [거부].
   - 기본 버튼(Enter·Esc)은 **거부**입니다. 제한 시간(기본 120초)이 지나면 실행하지 않습니다.
   - 승인한 뒤에도 실행 직전에 창·프로세스·요소 이름·입력란 값·좌표 화면을 다시 확인하고, 바뀌었으면 실행하지 않습니다.
5. 결과 보고와 각 단계의 결과(성공·실패·차단·건너뜀, 사용한 방법, 결과 검증)는 화면과 **기록**에 남습니다.

### 멈추기

- [일시정지]: 다음 동작 전에 멈춥니다. [재개]로 이어 갑니다(일시정지·승인 대기 시간은 작업 제한 시간에서 빠집니다).
- [중단] 또는 **Ctrl+Alt+F12**(전역) 또는 창 아래 [긴급 중단]: 즉시 멈추고 열린 승인 요청을 거부합니다.
- 예상하지 못한 프로그램의 창이 앞에 나타나면 작업이 **자동으로 일시정지**됩니다. 화면을 확인하고 재개하거나 중단하세요.

## 2. AI가 할 수 있는 동작

| 동작 | 설명 | 기본 승인 |
|---|---|---|
| launch_app | 허용 앱 중 실행 명령이 있는 앱 시작(인자 없이) | 앱 설정에 따름 |
| focus_window | 허용 앱 창을 앞으로(Alt+Tab 대신) | 아니오 |
| observe / read_element / wait_for | 화면 구조 수집, 요소 값·상태 읽기, 나타날 때까지 대기 | 아니오(읽기) |
| click / select / expand / collapse | UIA 패턴으로 버튼·항목·콤보·트리 조작 | 위험 이름(삭제·저장·보내기·로그인·확인 등)이면 예 |
| set_text | 입력란에 입력(replace) 또는 덧붙임(append) | 민감정보로 보이는 값·인증 입력란·긴 기존 내용 대체·키보드 줄바꿈이면 예. 비밀번호 칸은 거부 |
| toggle | 확인란을 켜기/끄기(이미 그 상태면 아무것도 안 함) | 위험 이름이면 예 |
| select_menu | 메뉴 경로 선택(예: 도구 › 대화상자 열기) | 마지막 항목이 위험하면 예 |
| scroll | 스크롤 | 아니오 |
| hotkey | 단축키. Ctrl+Z·Ctrl+C·Ctrl+A·Tab·Esc 등만 바로 실행, Enter·Delete·Ctrl+S·Alt+F4 등은 승인, Win 키·Alt+Tab·Ctrl+Alt+Del은 거부 | 표에 따름 |
| click_point | (비전 전용) 스크린샷 기준 좌표 클릭 | 기본 예(미리보기 포함). '좌표 클릭은 승인'을 꺼도 위치 확신도가 0.8 미만이거나 없으면 예 |
| list_directory | 허용 폴더의 목록(이름·크기·날짜) | 아니오(파일 내용은 읽지 않음) |
| wait / ask_user / finish | 대기, 사용자에게 질문, 결과 보고 | — |

파일을 삭제·이동·이름 바꾸는 파일 시스템 동작은 없습니다. 정리 제안은 보고만 합니다.

## 3. 화면별 사용법

### 창 검사기
- 왼쪽: 허용 앱 창 목록('모든 창 보기'를 켜면 차단된 창도 이름만 보임). 각 창의 자동화 허용 여부와 이유가 나옵니다.
- 가운데: UIA 요소 트리. 맨 위에 '구조 인식 가능 / 요소가 매우 적음 / 구조적 인식 불가 / 접근 거부'가 표시됩니다.
  - 구조적 인식 불가: 게임·그림으로 그린 화면, 접근성 트리가 꺼진 Chromium/Electron 앱 등. 이미지 입력을 지원하는 모델이 있으면 스크린샷 보조를 씁니다.
  - 접근 거부: 관리자 권한(또는 보호된) 프로그램. 일반 권한 프로그램은 Windows 정책(UIPI)상 조작할 수 없고, 이 앱도 시도하지 않습니다.
- 오른쪽: 창 정보(물리 픽셀 위치, DPI·배율, 논리 크기), 요소 속성, [화면에서 강조 표시], **직접 조작**(AI 없이 한 단계 — 같은 정책·승인·기록).

### 워크플로
- 예시 4개: 테스트 앱 카운트·입력, 메모장 입력(저장 안 함), 테스트 앱 확인란 읽기, 폴더 목록 읽기.
- 성공한 작업은 **작업 실행** 화면의 [워크플로로 저장]으로 저장할 수 있습니다(작업 안에서만 유효한 요소 참조는 AutomationId·이름으로 바꿔 저장).
- 매개변수는 `{{param:이름}}`으로 단계에 들어갑니다. 폴더 매개변수는 실행할 때 고른 폴더만 그 실행에서 읽기를 허용합니다.
- 실패 처리: 첫 실패에서 멈추고 실행된 변경과 실행하지 않은 단계를 기록합니다. 워크플로는 모델로 다시 계획하지 않습니다.
- 기본 예시는 지울 수 없고, 수정하면 '수정본'으로 저장됩니다.

### 기록
- 상태: 완료, 부분 완료(일부 변경 후 실패·거부·중단), 실패, 거부·차단, 중단됨, 비정상 종료로 중단, 사용자 입력 필요.
- 상세: '실행된 변경 N개 · 실행 여부 불확실 N개 · 실패·거부 N개 · 실행하지 않은 단계 N개', 단계별 정책 판단·승인·방법·메시지, 이벤트.
- 저장되는 내용은 비밀정보를 가린 요약입니다. 입력한 텍스트는 앞부분 40자와 길이만, 읽은 값은 1,500자까지(가림 적용) 남습니다. 스크린샷은 저장하지 않습니다(설정에서 켤 때만).

### 모델
- [연결 확인]: `GET /v1/models`(키 있으면 헤더로), Strata면 `/health`·`/v1/status`, llama.cpp면 `/props`를 읽습니다. 사용자 데이터는 보내지 않습니다.
- [이미지 입력 테스트]: 빨강·파랑 사각형 합성 이미지 두 장(화면 내용 아님)의 색을 맞혀야 통과합니다.
- [응답 형식 검사]: 실제 프롬프트로 가상 테스트 앱 화면을 보내 유효한 계획이 오는지, 올바른 버튼을 고르는지 확인합니다.
- **모델 성능 비교**: 고른 연결 × 시나리오(카운트 두 번, 문장 입력, 확인란 보고, 색상 선택)를 매번 새 테스트 앱에서 실행합니다.
  - '계획 유효'(모델이 스키마에 맞는 계획을 냄)와 'GUI 성공'(실제 화면이 기대 상태)을 따로 셉니다.
  - 승인이 필요한 단계는 자동 거부되어 '사용자 개입'으로 집계됩니다. 실행 중 계획 확인은 생략됩니다.
  - '실제 테스트 앱'을 끄면 가상 테스트 앱(MOCK)에서 실행하며 결과에 MOCK으로 표시됩니다.

### 안전 설정
- 허용 앱: ID, 이름, 프로세스 이름(쉼표 구분, .exe 없이), 실행 명령(비우면 AI가 실행할 수 없음), 조작 허용(끄면 읽기 전용), 실행 시 승인, 모든 조작 승인, 시스템 설정 앱(모든 변경 승인).
  - 기본: 테스트 앱·메모장·계산기(조작), Windows 설정(읽기 전용), 파일 탐색기(읽기 전용, 꺼짐).
  - 차단 목록에 있는 프로세스는 허용 목록에 넣어도 저장되지 않습니다.
- 승인 규칙: 계획 확인(권장), 모든 조작 승인, 확인·적용·예 버튼, 닫기·종료, 좌표 클릭, 지시처럼 보이는 화면 문구, 비전 사용.
  필수 규칙(파일 삭제·덮어쓰기 등)은 끌 수 없습니다.
- 변경은 **다음 작업부터** 적용됩니다. 실행 중인 작업은 시작할 때의 설정으로 끝까지 갑니다.

### 설정
- 스크린샷 저장은 기본 꺼짐입니다. 켜면 민감한 화면이 저장될 수 있다는 확인을 거칩니다.
- 백업은 검사(quick_check)를 통과한 경우에만 완료로 표시합니다. 복원 전에는 현재 데이터를 자동 백업합니다(작업 실행 중에는 복원하지 않음).

## 4. 비정상 종료 후

프로그램이 작업 도중 꺼지면(전원·강제 종료 등) 다음 실행 때:
- 진행 중이던 단계는 '실행 여부 불확실', 승인 대기 중이던 단계는 '취소', 남은 단계는 '건너뜀'으로 정리합니다.
- 변경이 있었으면 '부분 완료', 없었으면 '비정상 종료로 중단'으로 표시하고 대시보드·기록에 알립니다.
- **자동으로 다시 실행하지 않습니다.** 대상 앱의 상태를 직접 확인한 뒤 필요하면 기록에서 [같은 요청으로 다시 실행]을 눌러 새로 시작하세요.

## 5. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 연결 오류 | 서버가 켜져 있는지, 주소·포트(`/v1` 포함)가 맞는지. Strata 데스크톱 앱은 47831이 아닐 수 있음 |
| 인증 오류(401) | Serving API 키가 켜져 있으면 키 설정(환경 변수 또는 암호화 저장) |
| 모델 출력 거부 | [응답 형식 검사]로 확인. 작은 모델은 JSON을 지키지 못할 수 있음. '구조화 출력'을 JSON 스키마/JSON 객체로 바꿔 보기, 최대 출력 토큰 늘리기(추론 모델) |
| "추론만 하고 답이 없음" | 최대 출력 토큰을 늘리세요 |
| 요소를 찾지 못함 | 창 검사기에서 실제 이름·AutomationId 확인. 목록·콤보 항목은 먼저 펼쳐야 나타나는 경우가 있음 |
| 창을 앞으로 가져오지 못함 | 다른 프로그램이 포커스를 잡고 있음. 대상 창을 한 번 클릭한 뒤 재개 |
| 관리자 창 조작 불가 | 의도된 동작입니다(관리자 권한으로 실행하지 마세요) |
| Ctrl+Alt+F12가 안 됨 | 다른 프로그램이 사용 중. 대시보드에 경고가 나오며 [긴급 중단] 버튼은 항상 동작 |

진단: `wao windows`(창과 허용 여부), `wao tree --process notepad`(UIA 트리), `wao status --data-dir data`(DB·미완료 작업, 읽기 전용).
